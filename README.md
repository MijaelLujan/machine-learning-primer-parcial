# Práctica Primer Parcial: Machine Learning and Data Science

## Descripción

Proyecto de la práctica del primer parcial de la materia de Machine Learning and Data Science. Se trabaja con el dataset asignado por la docente para aplicar procesos de limpieza.

## Estructura del repositorio

```text
├── notebooks
├── data
├── .gitignore
├── README.md
├── pyproject.toml
└── uv.lock
```

* `src/` → código fuente del proyecto
* `notebooks/` → exploración y pruebas
* `data/` → dataset descargado

## Cómo levantar el entorno

1. Clonar el repositorio
2. Ejecutar `uv sync`

Si no tiene instalado la herramienta uv, puede consultar el siguiente [link](https://docs.astral.sh/uv/getting-started/installation/)

## Ejecucion de los cuadernos

Para ejecutar los cuadernos, si esta en vscode, le pedira el kernel, tiene que utilizar el entorno virtual .venv que creara el uv para que no tenga errores con las dependencias.
